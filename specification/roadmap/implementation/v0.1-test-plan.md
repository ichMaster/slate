# v0.1 — Тест-план

Тести розділені за одним принципом: **чи здатна машина перевірити це сама.**

| | Хто запускає | Що всередині |
|---|---|---|
| [`tools/m0-auto.sh`](../../../tools/m0-auto.sh) | Клод, без тебе | усе машинне: сюїти, прошивка, розбір логів |
| [`tools/m0-hands-on.sh`](../../../tools/m0-hands-on.sh) | **ти** | лише те, для чого потрібні очі й пальці |

Розділення не косметичне. Поки людину питали про те, що видно в лозі, вона
відповідала за машину — а машина при цьому мовчала про власні помилки. Тепер
кожна перевірка живе там, де її можна зробити чесно.

---

## Що робить машина (без тебе)

```bash
./tools/m0-auto.sh          # усе
./tools/m0-auto.sh host     # лише хост
./tools/m0-auto.sh device   # лише пристрій
```

| | Перевірка | Критерій |
|---|---|---|
| A1 | Сюїта стабільна | три прогони `pytest`, однакова кількість |
| A2 | Сюїти не змішались | продуктова окремо від codegen |
| A3 | Лічильник на сервері | +3, потім **нова сесія** читає те саме |
| A4 | Непроханий пуш | кадри годинника, `req_id` відсутній |
| A5 | Документ одним кадром | ≥50 блоків в одному `items` |
| B0 | Збірка і прошивка | `idf.py flash` |
| B1 | Завантаження | одне за 25с, без паніки, ledger витягнуто |
| B1 | Плата | зонд збігається з вердиктом BSP |
| B2 | Без сервера не падає | завантажень ≤1, паніки 0 |
| B3 | Мережа | чи є `wifi_ip=` у лозі |

Усе, що тут вимірюється, потрапляє в [ledger](v0.1-poc-ledger.md).

## Що робиш ти

```bash
./tools/m0-hands-on.sh
```

Пристрій має бути вже прошитий. ~2 хвилини.

**Чотири питання завжди:**

1. Що на екрані.
2. Чи виглядає екран **навмисно грубим** — це не вигадка, це критерій: M0 має
   бути потворним, і якщо він виглядає оформлено, милістоун поїхав.
3. Тач — скрипт скаже «ТИКАЙ ЗАРАЗ» і 15 с писатиме лог, поки ти тикаєш.
4. Чи реагував екран на дотик.

**Ще шість, якщо мережа підніметься** (скрипт визначає це сам із логу, не питає
тебе): чи тікає годинник · чи кнопка відповідає **миттєво**, а число мінялось
**пізніше** · чи плавно прокручується документ · чи видно рядок квадратиками
(тофу — це правильно, стандартний шрифт без кирилиці) · і головне — **вимкнути
й увімкнути Tab5**, після чого число має лишитись тим самим.

Чому саме ці. Кожне з них — про те, чого немає в лозі: вигляд, відчуття
затримки, плавність під пальцем, фізичне вимкнення живлення. Решту машина бачить
краще за людину.

## Стан

**A і B проходять.** Мережева частина пропускається: ESP32-C6 не відповідає по
SDIO, бо на ньому немає прошивки `esp_hosted`. Скрипт визначає це сам і пише
причину, а не вдає, що DoD перевірено.

DoD вимагає, щоб лічильник пережив перезавантаження пристрою. Поки пристрій без
мережі — це недосяжно, і **`v0.1.0` тегати не можна.**

Вимірювання з заліза: [v0.1-poc-ledger.md](v0.1-poc-ledger.md).

## Якщо щось не так

**Tab5 не видно** — на Tab5 один USB-C лише живить. Перевір: `ls /dev/cu.usbmodem*`.

**Скрипт завис на питанні** — `Ctrl-C`, звіт лишиться з тим, що вже зібрано.

**Не редагуй скрипт під час виконання** — bash читає файл порціями, і правка
ламає його на льоту.

Кожен прогін пише у власну теку `tools/evidence/`, тож перезапускати безпечно.
